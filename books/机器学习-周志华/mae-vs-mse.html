MAE 与 MSE：评价指标体现了什么偏好

1. 平均绝对误差 MAE

另一种避免正负误差抵消的方法，是先取绝对值再平均：

MAE = (|预测值1 - 实际值1| + … + |预测值n - 实际值n|) / n

MAE 的单位与目标相同。若预测重量以 kg 计，MAE 也以 kg 计。它是平均绝对误差，不是带正负号的平均误差。

2. 为什么可能选出不同模型

两个瓜实际都为 5 kg。C 预测 3、7 kg；D 预测 5、8 kg。

  • C 的绝对误差是 2、2 kg，MAE = 2 kg。
  • D 的绝对误差是 0、3 kg，MAE = 1.5 kg。

按 MAE，D 更好。但平方会放大大误差的影响，所以 MSE 可能给出不同的选择。指标应结合任务对错误的代价来选，并非任何一个都永远更好。

同一数据与单位下可比较模型的 MAE，也可比较 MSE；不要把 MAE 与 MSE 的数值大小直接比较，因为量纲不同。

3. 练习（已答对）

  1. C 的 MSE 是多少？
  2. D 的 MSE 是多少？
  3. 按 MSE 应选哪个？它与 MAE 的选择是否一致？

学习者回答

C 的 MSE = (4 + 4) / 2 = 4 kg²；D 的 MSE = (0 + 9) / 2 = 4.5 kg²。按 MSE 选 C，与 MAE 选 D 不一致，因为 MSE 对大误差的惩罚更大。

反馈：计算与解释全部正确。

4. 指标应与错误代价相匹配

  • 若每多错 1 kg，成本基本增加相同金额，MAE 更贴近这种线性代价。
  • 若误差增大后损失增长得更快，MSE 可能更符合目标，但真实代价未必恰好为平方关系。
  • 不能仅凭某个指标常用，就认定它适合所有任务。

下一问（已答对）

物流估重任务规定：无论高估还是低估，每相差 1 kg 都产生 2 元成本。只有 MAE 和 MSE 可选时，哪个更直接对应平均成本？为什么？

学习者回答：MAE，因为每相差 1 kg 成本都增加 2 元，是线性关系，平均成本就是 MAE 乘以 2。反馈：正确；更完整地说，系数单位为 2 元/kg，乘上 MAE（kg）得到平均每次预测的成本（元）。
